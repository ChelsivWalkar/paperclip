# Cloud Door Listing Readiness

A listing may be proposed for founder approval only when **every** field is real and verified:

- [ ] Product title (clear, honest, no keyword stuffing)
- [ ] Supplier name and source URL
- [ ] Actual landed cost (supplier price + freight/duty)
- [ ] Selling price in INR and unit contribution (checked by Ops & Finance)
- [ ] Rights-cleared images (supplier-licensed or own photos)
- [ ] Accurate specifications, age range and materials
- [ ] Safety / compliance labels for toys, baby and electronics
- [ ] Warehouse stock level and delivery ETA
- [ ] Return and warranty terms
- [ ] Collection assigned (one of the 10 Cloud Door collections)
- [ ] For Bibles and Christian books: authorized resale edition

If any field is missing, mark the listing **Not ready** and list the missing fields. Never fill gaps with guesses.
