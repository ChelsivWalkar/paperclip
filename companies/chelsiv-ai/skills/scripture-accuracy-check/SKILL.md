# Scripture Accuracy Check

Run on every draft that quotes or teaches from the Bible.

1. **Reference** — book, chapter and verse are correct and the verse exists.
2. **Wording** — text matches the named translation word for word. If paraphrased, label it "paraphrase".
3. **Translation** — name the translation (KJV, ESV, NIV, NKJV, etc.). Respect publisher licensing limits for long quotations.
4. **Context** — read the surrounding passage. Confirm the post's meaning matches the author's intent; no proof-texting.
5. **Christ-centred** — the message points to God's character and Christ's love, not fear or shame.
6. **No inventions** — no made-up quotes attributed to people, no fictional testimonies presented as real.
7. **Language versions** — translated captions keep the same meaning; prefer an established Bible translation in that language.

Output a short note on the issue: `Scripture check: PASS` (or `NEEDS FIX` with the exact problem and suggested correction).
